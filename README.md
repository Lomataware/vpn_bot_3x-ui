# 🚀 VPN Telegram Bot (3x-ui Edition)

Полнофункциональный Telegram-бот для продажи и автоматической выдачи VPN на базе панели **3x-ui (MHSanaei/3x-ui)**.

## ✨ Основные возможности
* **Интеграция с 3x-ui API (`xui_api.py`):**
  * Автоматическое создание клиентов, продление подписки, сброс трафика и отключение через REST API 3x-ui.
  * Автоматическая сборка клиентских ссылок `vless://` (с параметрами Reality `pbk`, `sid`, `sni`, `fp`, `flow=xtls-rprx-vision`), `hysteria2://` или `trojan://` напрямую из настроек инбаунда в 3x-ui, либо выдача единой ссылки подписки (`XUI_SUB_URL`), если в 3x-ui включен сервис подписок (в том числе с Hysteria 2 и несколькими инбаундами).
* **Пробный период:**
  * Выдача бесплатного теста (по умолчанию 3 дня) в один клик с защитой от повторной активации.
* **Прием платежей:**
  * Ручная оплата по СБП / карте с подтверждением администратором (`/approve`).
  * Автоматическая оплата криптовалютой через **@CryptoBot** (USDT, TON, BTC и др.).
* **Безопасность:**
  * Веб-панель 3x-ui слушает только `127.0.0.1:2053` и защищена от внешнего сканирования (доступ через SSH-туннель).
  * База данных SQLite работает в режиме `WAL` с проверкой целостности при запуске.

## 🚀 Быстрая установка

### Требования
* VPS с **Ubuntu 22.04** или **24.04 LTS** (права `root`).
* Домен с **A-записью**, указывающей на IP-адрес сервера.
* Токен бота от [@BotFather](https://t.me/BotFather) и ваш Telegram ID.

### Запуск автоустановщика
Скопируйте файлы проекта в `/root/vpn_bot/vpntg` (или укажите Git-репозиторий) и запустите:

```bash
chmod +x install_vpn.sh
sudo ./install_vpn.sh
```

Скрипт автоматически:
1. Проверит IP и DNS-запись домена.
2. Настроит **UFW** (`22/tcp`, `80/tcp`, `443/tcp`, `443/udp`).
3. Выпустит сертификат **Let's Encrypt**.
4. Установит **3x-ui** на `127.0.0.1:2053`, сгенерирует ключи X25519 и создаст Inbound #1 (`VLESS + Reality` на порту `443`).
5. Создаст виртуальное окружение Python, заполнит `.env` и запустит сервис `vpnbot.service`.
6. Сохранит все пароли и ключи в `/root/install_credentials.txt` (`chmod 600`).

## 🛠 Команды администратора

Доступны пользователям, чей Telegram ID указан в `ADMIN_ID` или `ADDITIONAL_ADMINS`:

| Команда | Описание |
| :--- | :--- |
| `/stats` | Статистика пользователей и оплат |
| `/pending` | Список платежей, ожидающих подтверждения |
| `/approve <payment_id>` | Подтвердить платеж и выдать подписку на 30 дней |
| `/issue <user_id> <days>` | Выдать или продлить подписку пользователю вручную |
| `/broadcast <текст>` | Рассылка сообщения всем пользователям бота |

## 🔐 Доступ к панели 3x-ui

Пробросьте порт `2053` через SSH-туннель с вашего компьютера:

```bash
ssh -L 2053:127.0.0.1:2053 root@<IP_СЕРВЕРА>
```

После этого откройте в браузере: `http://127.0.0.1:2053/` (логин и пароль находятся в `/root/install_credentials.txt`).
