# 🚀 VPN Telegram Bot (3x-ui Edition — Fixed)

Полнофункциональный Telegram-бот для продажи и автоматической выдачи VPN на базе панели **3x-ui (MHSanaei/3x-ui)**.

## 🔧 Что исправлено в этой сборке
1. **Совместимость с 3x-ui v2.x и v3.x (`xui_api.py`):**
   * Устранено падение `TypeError` на `json.loads()` при чтении `settings` и `streamSettings`, когда панель возвращает вложенные словари (`dict`).
   * Автоматический подбор типа `tgId` (`int` и `str`) при вызовах `addClient` и `updateClient`, а также поддержка новых клиентских маршрутов `/panel/api/clients/add`.
   * Поддержка `X-CSRF-Token` (`/csrf-token`) и корректная передача сессионных cookies в `httpx`.
   * Автоматическое обнаружение настроек локальной БД `/etc/x-ui/x-ui.db` (схема `http`/`https`, порт и `webBasePath`), если базовый URL в `.env` недоступен.
   * **Автоматическое создание инбаунда VLESS + Reality (порт 443)** при первом запросе, если в панели 3x-ui ещё не создано ни одного инбаунда.
   * Выдача прямого `vless://` ключа вместе со ссылкой подписки (`Sub URL`).
2. **Надежная обработка оплат (`handlers.py`, `database.py`):**
   * Исправлен порядок смены статуса платежа CryptoBot (`check_`): платеж переводится в статус `paid` только после успешного создания подписки в 3x-ui.
   * Добавлен поиск счета в SQLite по `external_id` (`get_payment_by_external_id`), чтобы проверка оплаты работала даже после перезапуска бота.
3. **Исправление установщика (`install_vpn.sh`):**
   * Очистка дублирующихся записей в таблице `settings` базы `/etc/x-ui/x-ui.db` перед записью `webBasePath` и `webPort`.
   * Передача `X-CSRF-Token` при создании инбаунда и совместимость парсинга ключей `xray x25519` со всеми версиями Xray-core.

## 🚀 Быстрое обновление на существующем сервере
Распакуйте архив в `/root/vpn_bot/vpntg` (не перезаписывая ваш `.env`) и перезапустите сервис:

```bash
systemctl restart vpnbot
journalctl -u vpnbot -f
```
